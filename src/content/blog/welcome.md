# Chào mừng đến với Astro Template

Dự án này được cấu hình theo chuẩn **Production-ready**:

- **Astro 5+** Core với Content Layer API
- **Tailwind CSS v4** tích hợp qua `@tailwindcss/vite`
- **TypeScript Strict** với Path Alias `@/*`
- **ESLint v9+ Flat Config** & **Prettier**
- **Husky** & **Commitlint** cho Conventional Commits
